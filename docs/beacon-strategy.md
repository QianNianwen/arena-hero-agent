# 冠军信标：抢夺与运营策略

日期：2026-08-15。规则基准 gameplay v0.14（文档包核对于 2026-08-06），SDK 0.2.9。
本文规则结论均可回溯到官方规则文档；标【待实测】者为推演，落地需按离线优化流程验证。
配套阅读：[战术研究](tactics-research.md)、[威胁响应](threat-response.md)。

## 一、先看现状（tick 110550 实测）

| 项 | 值 |
| --- | --- |
| 我方 Core | `[-301, -185]`，满血满盾 |
| 信标位置 | `[57, -219]` |
| 直线距离 | **392 格（曼哈顿）** |
| 我方编制 | 18 Worker / 8 Vanguard / 3 Ranger，人口 29 |
| 当前策略 | `--beacon-policy pursue` |

公开排行榜 `beacon_ticks_held`（累计持有 tick 数）：

| 名次 | 玩家 | 持有 tick | 占全局 tick 比 |
| ---: | --- | ---: | ---: |
| 1 | jerkman | 50,149 | ≈45% |
| 2 | henryxiaoyang | 32,198 | ≈29% |
| 3 | arenehero | 9,412 | ≈9% |

**结论先行：当前配置下 `pursue` 是空转的，一个 tick 都没在追。** 两道门同时关着：

1. `_beacon_campaign_ready`（arena_farmer.py:4674）要求人口 ≥40，我方 29 —— 不达标；
2. 即便达标，单位每 tick 走 1 格，392 格 = **单程 392 tick ≈ 98 分钟**，往返 3 小时以上，
   且信标本身在漂移，到场时大概率已不在原地。

而且 `pursue` 不是"什么都不做"——它有**隐性成本**：`_scout_target`（arena_farmer.py:3690-3709）
在 pursue 下会把全部侦察射线朝信标方向排序。也就是说，我方 18 个 Worker 的探索方向
正被一个 392 格外、由榜一常年霸占的目标持续牵引。这是纯亏损。

## 二、规则底层（决定一切战术的硬约束）

| 规则 | 战术含义 |
| --- | --- |
| 全服只有 1 个信标，不可摧毁，起点 `[0,0]`，重启不重置 | 是唯一的、永久的争夺焦点 |
| **坐标对所有人永远公开** | 携带者的位置等于全服广播 |
| **GROUND/CARRIED 状态与匿名 `carrier_id` 只在能看见该格时可见** | 看不见时只知道"在哪"，不知道"谁拿着、是否有人拿" |
| 不占格容量，不挡移动、视野、弹道 | 不能用它当掩体 |
| 拾取需**整个动作**，且必须**已在**该格；路过不自动拾取 | 移动与拾取不能同 tick 完成 |
| **活着的携带者无法被直接夺取** | 想抢必须先杀死携带者 |
| 携带者死亡/主动丢弃/其 Core 被毁 → 落在携带者**最终实际位置**，且**当 tick 内任何人都不能拾取** | 掉落后有一个空窗 tick |
| 同 tick 多个对象抢拾 → 最小 UUID 胜 | 只可能发生在同一玩家的两个单位同格时 |
| 信标动作在 Worker 动作**之前**结算 | 拾取当 tick 即享采集加成；丢弃当 tick 即失去 |
| 持有者 Core 护盾上限 5→10；拾取不送盾；失去时超过 5 的部分立即削回 5 | 额外 5 点盾要自己花 5 资源、5 tick 去填，且会蒸发 |
| 空载 Worker 采集 1→**2**（掉落货堆同样最多 2） | 全局经济翻倍 |
| 一次采集消耗整个节点，无论产出 1 还是 2 | 翻倍的是产出，不是节点消耗速度 |
| 已装载的 2 点货，在失去信标后仍是 2 | 不必抢在失去前送回 |
| 迁移中的 Core 不能拾取/丢弃；但可以携带（信标停在其逻辑位置） | Core 携带 + 迁移是合法的 |
| 普通非迁移状态的 **Core 本身也可以拾取** | 携带者不限于单位 |

## 三、值多少：收益与暴露的量化

### 3.1 收益

1. **经济翻倍（首要价值）。** 采集加成对全体 Worker 生效，与携带者在哪无关。
   18 个 Worker 的往返物流成本不变，每趟产出 ×2 ≈ **资源收入 +100%**。
   按当前档位（人口 30-34：先锋 22 / 游侠 26），收入翻倍等于建军时间对半砍。
   这是全游戏唯一的百分之百级经济乘数。
2. **Core 护盾上限 +5。** 相当于 +5 有效血量，但需另花 5 资源、占用 5 个 tick 的
   Core 动作（修盾每 tick 固定 1 点，且与 SPAWN/HEAL 三选一），且失去信标时立即蒸发。
   属于"局势稳定时才做"的锦上添花，不是抢夺理由。
3. **排行榜**：`beacon_ticks_held` 按累计持有 tick 计分，持有即计分。

### 3.2 暴露成本（现行实现的真问题）

坐标永久公开，因此**携带路线就是情报泄露**。现行实现让跑者取到信标后
回到 Core 3 格内驻留（`BEACON_RETURN_RADIUS = 3`，arena_farmer.py:5583-5602），
等价于向全服公布我方 Core 坐标，并为
[战术研究 3.2 的斜角盲狙](tactics-research.md) 直接提供瞄准点。

**关键不对称：静止可以伪装，移动必然暴露。**
坐标不动时，外人无法区分"躺在地上"和"被静止单位持有"——除非他能看见那一格。
坐标逐 tick 移动时，任何人无需视野即可断定"有人拿着，且正在往那个方向走"。
这条不对称是下面全部运营设计的支点。

## 四、抢夺（Capture）

### 4.1 Go/No-Go：先算账再出兵

出兵前必须过三关，缺一即放弃：

| 关卡 | 判据 | 理由 |
| --- | --- | --- |
| 距离 | 单程 ≤ **60-80 格**（≈15-20 分钟） | 超出则信标漂移 + 缺员防守的代价压倒收益 |
| 兵力 | 派出后仍满足最低守卫层（1V+1R，成熟期 2V+2R） | Core 生存永远高于信标 |
| 威胁 | 无当前 Core 攻击、无逼近敌军 | 沿用现有 `_beacon_campaign_ready` 的这部分判据 |

**不要用人口当门槛。** 经济加成在扩张期最值钱，等到 40 人口再去拿，等于把
最需要翻倍的阶段整个跳过。真正该看的是**距离**和**可派出的护卫**。

### 4.2 情形 A：地面无主信标 —— 抢占格子即锁定

核心机制：**不同玩家的对象永远不能在同一格结束回合。**
所以只要我方单位站上信标格，敌方就再也进不来，等于独占。

时序（`C` = 信标格）：

```
tick N     单位移动到 C（动作 = MOVE）
tick N+1   PICKUP_BEACON（动作 = 拾取），同 tick 采集加成即生效
```

- 移动（第 4 步）先于拾取（第 6 步）结算，但一个单位每 tick 只有一个动作，
  所以**移动与拾取无法压缩到同一 tick**，抢占后必然有 1 tick 的裸露期。
- 若敌我同时想进 C，**双方移动全部失败**（争抢目的格规则）。因此接近时
  应从两个不同方向各派一个单位：一个被顶住，另一个仍可能进入。
- 已占住 C 之后，敌人唯一的办法是杀死我方占位单位。所以占位的应当是
  4HP 的 Vanguard，不是 2HP 的 Worker 或 Ranger。

### 4.3 情形 B：敌方携带中 —— 必须先杀携带者

活着的携带者不可被夺取，只能击杀。难点在于**携带者身份是隐藏的**
（匿名 `carrier_id` 只在看得见那一格时可见），但坐标公开——所以我们
永远知道"该打哪一格"，只是不知道打的是谁。

这正好契合 [战术研究 3.1](tactics-research.md) 的盲狙位：
**斜向 3 步 = 曼哈顿 6，超出全部对象的视野半径**，而 `shoot_cell` 允许对
看不见的格开火，打空只产生私有 `SHOT_MISSED`、零成本。
于是可以对着公开的信标坐标持续盲狙，对方在被打掉血之前都不知道火从哪来。

完整时序（`C` = 携带者所在格）：

```
tick N     击杀携带者              → 信标落在其最终位置 C，本 tick 任何人都不能拾取
tick N+1   我方单位移动进 C        → 敌方同样在抢，撞车则双方都进不去
tick N+2   PICKUP_BEACON           → 到手
```

**从击杀到到手要 3 个 tick，中间两个 tick 必须守住 C。**
因此击杀那一刻，我方必须已经有单位**紧贴 C**，且有足够火力压住来抢的人。
理想配置：2 个 Ranger 在斜角盲狙位负责击杀，1-2 个 Vanguard 贴在 C 的正向邻格
负责第 N+1 tick 进位、第 N+2 tick 拾取并扛住反扑。

注意：携带者死亡时 `WORKER_CARGO_DROPPED` 之类的掉落也在同格，
但信标不占容量槽，不影响进位。

### 4.3.1 重要限制：盲狙只对**静止**携带者有效

移动（第 4 步）先于战斗（第 8 步）结算，而我方 state 里看到的信标坐标是
**上一 tick 结算后**的位置。所以：

- 携带者**静止不动** → 盲狙命中；
- 携带者**正在移动** → 信标跟着它走，打上一个坐标必然落空
  （只产生私有 `SHOT_MISSED`，零成本，但浪费了 Ranger 的动作）。

判定方法不需要视野：**连续两个 tick 比对公开坐标**。坐标不变 = 静止（可盲狙，
也可能只是躺在地上）；坐标在变 = 有人携带且在移动（需要预测射击，
打它的必经格，参考[战术研究 5.2](tactics-research.md)）。

### 4.4 情形 C：抢不到就拒止（Denial）

**争抢目的格 → 全部失败**这条规则可以反过来用：只要每 tick 派一个单位
跟敌方抢同一个信标格，谁都进不去，信标就永远躺在地上。
成本是一个廉价单位的动作，收益是让对手拿不到 100% 的经济加成。

前提是拒止单位得活着（它站在 C 的邻格，不是 C 上）。对方可以杀掉它——
所以拒止适合在我方有火力覆盖的区域用，不适合深入敌区硬耗。

**拒止的战略价值不低于抢夺。** 榜一持有率 45%，意味着他长期享受双倍经济；
哪怕我们拿不到，把他的持有streak 打断也是净收益。

## 五、运营（Operating）

### 5.1 核心原则：静默持有，远离 Core

三条硬规矩：

1. **绝不带回 Core 附近。** 现行 `BEACON_RETURN_RADIUS = 3` 的回巢行为必须废弃——
   它把我方 Core 坐标公开给全服。
2. **停下来，别巡逻。** 静止坐标与"躺在地上"不可区分；移动坐标必然暴露有人携带。
   把携带者钉在一个固定格上，对外看起来就像一枚无人认领的地面信标。
3. **选一个有掩护的死角。** 障碍口袋、进入通道少的位置最好；
   参考 [战术研究 4.2 的地形防御分](tactics-research.md)：可被射击的格越少越好。

这三条合起来构成"**信标哨所**"：一个远离 Core、静止、设防的假地面信标。
来"捡便宜"的人会一头撞进我们的火力网，而我们的 Core 位置始终没有泄露。

哨所编成建议【待实测】：1 个 Vanguard 携带（4HP，全游戏最耐打的单位）+
1-2 个 Ranger 在斜角位提供盲区反击。规模不必大——它的防御力来自
"没人知道这里有埋伏"，而不是兵力。

#### 静止的代价：既是伪装，也是靶子

把 4.3.1 节反过来看：静止携带虽然
隐藏了"有人在拿"，却让我们成为**固定的盲狙目标**——任何人都可以对着公开坐标
`shoot_cell`，打空零成本，命中就是白赚。对手甚至不需要确认那里有没有人，
试探性开火本身就是划算的。

所以哨所选址不能只看"隐蔽"，必须让**斜向 3 步（曼哈顿 6）的四个盲狙位不可用**：

- 首选：四条斜线上有障碍遮断弹道的位置（障碍挡弹道的规则见规则文档"只有障碍
  会挡住 Ranger 射击"）；
- 次选：贴着地图障碍口袋，使可射击我方的格数最少
  （[战术研究 4.2 的地形防御分](tactics-research.md)可直接复用）；
- 都做不到时：**每隔若干 tick 挪一格**。移动会暴露"有人携带"，但能打断对方的
  盲狙锁定；在被试探性火力打中过之后，这个交换是划算的。

一句话：**静止 + 弹道被地形封死 = 最优**；静止 + 空旷 = 最差（既被当靶子又跑不掉）。

### 5.2 携带者轮换：同格交接（1 tick 代价）

携带者受伤后不能就地治疗（治疗必须在己方静止 Core 所在格），
但**格容量是 2，同一玩家的两个单位可以同格**，于是可以无损交接：

```
tick N     两个己方单位同处 C；携带者 DROP_BEACON
           （本 tick 信标在地上 → 损失 1 tick 采集加成；
             但规则规定当 tick 无人可拾取，且我方占着格子，敌方进不来）
tick N+1   同格的另一单位 PICKUP_BEACON → 加成同 tick 恢复
```

**总代价：1 个 tick 的采集加成。** 换来的是把残血携带者送回 Core 治疗，
或把即将被集火的携带者换成满血单位。这是运营中最实用的一招。

### 5.3 护盾：只在太平时填

信标把 Core 护盾上限抬到 10，但那 5 点要自己花 5 资源、连续 5 个 tick
用 Core 动作去修（修盾每 tick 固定 1 点），而且**失去信标时立刻蒸发**。
所以：只在稳定持有、无威胁、且没有更值钱的 Core 动作（生产/治疗）时才填。
被压制时优先治疗与生产，别为了一层会蒸发的盾浪费动作。

### 5.4 经济：拿到手立刻兑现

加成是全局的、与携带者位置无关，所以拿到的那一刻起就该**满负荷采集**。
采集加成对掉落货堆同样适用（最多 2）。
已装载的 2 点货在失去信标后仍是 2，不必抢在失去前送回。

### 5.5 什么时候该主动放弃

- **Core 进入生存危机时**：Core 被摧毁 → 全部单位死亡 → 信标照样掉。
  Core 生存永远排第一，不要为了保信标削弱本土防御。
- **哨所被大部队找上门**：打不过就让携带者带着信标往远离 Core 的方向撤，
  实在保不住就丢在难以接近的位置——至少让对手也要花 3 个 tick 才能接手。

### 已落地的止损

上表前三项已实现。在当前 392 格的距离下，新的距离门槛会让 campaign 自动保持关闭，
`pursue` 也不再扭曲侦察方向——18 个 Worker 恢复按"最久未探索 + 高资源配额"
的正常逻辑均衡展开，无需再手动切 `hold`。信标一旦漂到 80 格以内，
campaign 会自动启动。

## 七、一页速查

**抢**：算距离（>80 格不去）→ 地面无主则抢占格子（占住即独占，敌方进不来）→
敌方携带则先杀（比对两个 tick 的公开坐标：不动才能盲狙，在动要打预测格）→
击杀前必须已贴位，掉落后需 3 个 tick 才能到手 → 抢不到就每 tick 争抢该格拒止。

**运**：远离 Core（坐标永久公开）→ 静止持有伪装成地面信标，但**必须选弹道被
地形封死的位置**，否则静止就是活靶 → 1V 携带 + 斜角 Ranger 掩护 →
残血用同格交接换人（代价仅 1 tick）→ 太平时才填那 5 点会蒸发的盾 →
Core 危急时果断放弃。

**记住三句话**：活着的携带者抢不走；移动的坐标必然暴露、静止的坐标必然挨打；
Core 比信标重要。
